# 前端改版汇总 · 2026-09-07

本次参考提供的移动端设计图，采用冰白背景、深蓝标题、青绿色交互和少量金色段位点缀，重新设计原生微信小程序。名人堂暂不加入页面或导航，未进行线上发布。

## 页面变化

| 页面 | 改版内容 |
| --- | --- |
| 首页 | 玩家状态卡、队伍/消息/认证快捷入口、赛事搜索与状态筛选、报名进度、截止时间、加载失败重试和空态 |
| 导航 | 统一品牌栏、按微信胶囊实际位置预留空间、分区抽屉、游客登录入口 |
| 我的队伍 | 队伍身份、真实水平分、阵容、审核状态、入队申请和招募操作；窄屏与长昵称适配 |
| 所有队伍 | 搜索和评分排序、队伍资料卡、可滚动阵容详情、申请入队 |
| 认证 | 当前真实段位与 S 段星级、在校/段位两步认证、截图回显和平台截图指引 |
| 个人与登录 | 玩家资料卡、资料编辑与取消、快捷入口、森林徽标、协议勾选与游客浏览 |
| 赛事与管理详情 | 赛事主卡、报名状态、阶段切换、比分卡、排期状态与底部弹层；管理操作沿用原权限 |
| 消息、设置、规则及管理列表 | 同步卡片、颜色、间距和标题；消息补充游客、加载及失败提示 |

## 业务与交互

- 展示接口中的真实数据：个人评分仍按原有 0–100 规则；队伍详情按评分最高的 5 名成员合计。未采用参考图中的虚构分数、副队长或 AI 置信度。
- 保留报名、入队、审核、上传及排期逻辑。队长安排比赛时间，管理端录分；上一轮修复的个人报名转整队报名入口保留。
- 决赛未结束时不提前显示冠军、亚军；用户端与管理端保持一致。
- 修正绝对头像/截图地址回显、头像更新后段位显示、详情接口缺少总评分/队长名称时的展示。
- 登录、保存资料和上传头像增加处理中状态，避免重复点击；请求失败与真实空列表分开呈现。

## 体积与请求

- 新增 6 个本地 SVG 徽标/图标，合计约 2 KB，没有引入大幅位图、额外 UI 库或名人堂接口。
- 去除首页赛事卡持续发光动画，使用静态装饰和轻量按压反馈。
- 首页复用导航栏的用户信息与在途请求；赛事状态筛选在本地完成，并防止旧搜索响应覆盖新结果。
- 消息邀请和段位申请并行读取；游客不请求这些需要登录的数据。

这些是具体开销改进，尚未进行微信端帧率、内存峰值或加载耗时基准测试，不能据此量化提速比例。

## 微信编译反馈修复

开发者工具反馈 `team.wxml` 人才市场的 `wx:else` 与 `wx:for` 同节点，产生 `wx:if not found` 编译错误。已改为外层 `<block wx:else>` 包裹内部循环，原邀请按钮和列表数据绑定保留。

此前浏览器预览只检查标签闭合，未检测此类 WXML 条件作用域。现预览工具在解析时校验完整条件链，包括隐藏弹层；新增全项目模板扫描及人才市场加载、失败、空列表、有选手四类状态测试。

修复后使用本机微信开发者工具自带的 `wcc.exe` 离线编译，全部 **14 个 WXML 文件通过**。这是模板编译验证，完整交互仍需开发者工具与真机验收。

## 段位徽章补齐

此前认证页只显示大段位字母盾牌，首页个人卡片只接入了段位文字。本次增加 15 枚本地 SVG：D；C/C+/C++、B/B+/B++、A/A+/A++；普通 S、金 S、钻 S、魔王 S；待认证占位图标。D 按实际规则只有一个等级。

加号使用图标内的路径字形，S 徽章按 10、25、50 星切换金、钻、魔王档，旁边保留真实星数文字。首页、认证页、个人资料页统一通过 `utils/rank.js` 映射同一图标。所有图标合计约 19 KB，没有额外图片接口或字体依赖。

段位补齐后 29 项前端回归通过，覆盖细分段位资源、S 星级边界和三个页面真实模板的图标接入；14 个 WXML 再次通过本机微信编译器检查。
