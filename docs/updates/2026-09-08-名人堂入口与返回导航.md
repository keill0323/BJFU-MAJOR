# 2026-09-08 名人堂入口与返回导航

本轮调整首页入口和跨页面导航，解决名人堂横幅突兀、用户必须通过侧边栏才能返回赛事中心的问题。

## 首页入口

- 去掉独立的金色名人堂横幅，将名人堂放入个人卡片下方的快捷入口，顺序为「我的队伍、所有队伍、名人堂、消息、认证中心」。
- 五个入口统一图标尺寸、青绿色线条、底色和文字层级；新增本地矢量奖杯 `honor.svg`，同时用于侧边栏，改善浅色背景上的辨识度。
- 点击名人堂保留原首页页面栈，返回时可以保留此前的搜索、筛选和滚动位置。

## 返回赛事

| 页面类型 | 返回入口 |
| --- | --- |
| 名人堂、我的队伍、所有队伍、个人中心、消息、认证、设置 | 自定义页头左侧常规显示「‹ 返回赛事」，同时保留当前标题及侧边栏按钮，预留微信胶囊宽度 |
| 赛事详情、管理后台、后台赛事详情、登录、参赛须知 | 原生标题下增加共用 `event-return` 组件，原生的上一页返回仍保留 |
| 赛事首页 | 保留现有首页页头，不重复显示返回入口 |

返回入口不依赖数据加载或登录状态，直接打开、加载中或请求失败时仍可使用。共享的 `utils/navigation.js` 查找页面栈中最近的赛事首页；存在则通过 `navigateBack` 返回，不存在则通过 `reLaunch` 打开 `/pages/index/index`。返回失败时尝试显式打开首页；若仍失败，显示可重试提示并释放点击锁。连续点击共用一次导航，侧边栏的赛事中心也复用这套行为。

## 验证与交付

- 导航回归覆盖准确返回赛事首页、多层页面栈、直接进入页面、重复点击、失败兜底、重试，以及全部已注册非首页的入口覆盖。
- 当前 113 项前端回归通过：全量 112 项通过后，最后新增的页面覆盖用例与导航组共 12 项再次通过；本轮未修改或重跑后端逻辑。
- 全部 16 个 WXML、17 个 WXSS 使用微信开发者工具自带编译器通过编译；24 个离线预览状态生成成功。
- 首页五个快捷入口已在微信开发者工具模拟器中确认显示。随后用户按 Esc 停止界面操作，因此未完成返回按钮的逐页点击及真机验收。
- 本轮仅修改前端、回归用例和说明文档，没有部署后端或上传、发布小程序。
